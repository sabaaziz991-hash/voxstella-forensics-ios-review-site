VoxStella Forensics

Privacy Policy

VoxStella Forensics is designed as a local native iOS app. The app does not include an account system, advertising SDK, tracking SDK, analytics SDK, push notifications, or a remote analysis service.

Bundled example cases are included in the app. User-created saved cases are stored locally in the app container unless the user exports or shares a report.

Location search is optional and uses Apple's geocoding services only when the user chooses search. Manual latitude and longitude entry remains available.

The optional Apple Watch app records the time when the user marks a moment. If the user allows location access, the watch also reads its location at that moment, and only then. The moment is sent only to the user's paired iPhone, and the iPhone sends case summaries to the watch so they can be viewed there. This exchange uses Apple's WatchConnectivity between the user's own devices and is not sent to the developer or any third-party service.

The app periodically checks this GitHub Pages site for rule-data updates. These requests do not contain case inputs, charts, saved cases, or exported reports. Analysis remains on the device.

StoreKit is used for in-app purchases and subscription entitlement status. Apple processes purchase and subscription activity under Apple's own terms and privacy practices.
